🔐 Đổi Mã PIN Chủ Web

Trên web thật, nút Quản lý luôn ẩn hoàn toàn. Bạn mở bằng cách chạm 5 lần vào Ảnh đại diện (trong 3 giây) rồi nhập Mã PIN này.

☁️ Đồng bộ thẳng lên GitHub Pages

Chỉ cần dán GitHub Token 1 lần duy nhất trên máy bạn. Về sau mỗi lần thêm link hay đổi ảnh chỉ cần bấm ☁️ Lưu thẳng lên Web!

🔒 An toàn 100%: Token chỉ lưu riêng trên điện thoại này, tuyệt đối không bị đẩy vào file data.json.

⚡ Cách lấy Token GitHub trong 1 phút:

  1. Vào github.com/settings/personal-access-tokens/new (đăng nhập tài khoản GitHub của bạn).
  2. Đặt tên tùy ý (VD: BioAdmin), mục Expiration chọn No expiration (hoặc 1 năm).
  3. Mục Repository access chọn Only select repositories → tích chọn kho Triizbakhi.github.io.
  4. Bấm Repository permissions → tìm mục Contents → đổi thành Read and write.
  5. Kéo xuống bấm Generate token → Copy mã dán vào ô trên rồi bấm Kiểm tra kết nối GitHub!
